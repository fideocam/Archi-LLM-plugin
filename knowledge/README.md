# ArchiGPT knowledge pack (copy to `~/.archigpt/knowledge`)

This folder is a **template** for company RAG context. Copy it, then replace placeholders with your organisation’s text.

ArchiGPT retrieves a few matching `.md` / `.txt` / `.csv` files on each Ask and adds them as COMPANY KNOWLEDGE. See [docs/RAG_OLLAMA.md](../docs/RAG_OLLAMA.md).

Suggested live location:

```
~/.archigpt/knowledge/
```

The same pack can be shared with [EaGPT](https://github.com/fideocam/sparxgpt) (`%AppData%\EaGpt\knowledge`).
