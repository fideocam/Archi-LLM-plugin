# Example: application layer viewpoint

When the user asks for an **application** landscape or services:

Typical elements: ApplicationComponent, ApplicationInterface, ApplicationService, ApplicationProcess, DataObject.

Typical relationships: ServingRelationship (component/service to user of the service), RealizationRelationship (component realizes service), AccessRelationship (component/service to DataObject), CompositionRelationship or AggregationRelationship (coarse component to parts).

Name components after CMDB application names when those are in COMPANY KNOWLEDGE.
